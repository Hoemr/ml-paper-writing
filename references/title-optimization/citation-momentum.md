# 近一年引用增长与标题热词推荐

明确启用完整标题检索优化时默认执行；只要求热词推荐时仅执行本步骤。
普通标题润色、全量论文写作、单独撞名检查均不触发。
术语本身没有引用数，测量对象是明确界定的相关文献集合。引用热度不等于
搜索量，也不证明标题含该词会提高排名或引用量。

## 候选发现与语义资格

从论文任务、方法、证据、目标社区及相关文献提取一小组术语和规范同义词。
每个词记录含义、本论文证据位置、目标检索问题及标题适配理由。任务、核心
方法或真实研究对象可进入标题；仅作 baseline、背景或顺带讨论的词通常只能
用于摘要/相关工作。跑过 benchmark 不代表论文以该方向为核心。
语义近似但不等价的热词不得替换实际方法。比较同领域或真实相关的相邻领域
候选，合并同义词、消除歧义、去除预印本与正式版重复，记录版本选择。

## 固定日期和文献集合

以用户时区当天 D 为准，最近窗口 R=[D−365 天,D)，对照窗口
P=[D−730 天,D−365 天)。两者等长且不重叠，截至昨天；不是自然年。
API 日期含首尾时，结束日期分别为 D−1 天、D−366 天。报告实际日期和检索时间。
用户指定其他窗口时遵从，保持可比口径。

按术语/同义词与主题限制检索，读标题摘要确认相关性。默认先选 5–10 篇主题
相关的代表论文作筛选，不按待测增速挑选。记录检索式、候选总量（可得时）、
全部入选 ID、排除原因及样本量。代表样本不是全领域统计。
主比较使用 P 开始前已发表、两个窗口均可观测的同一组论文，不随窗口换集合。
近两年才出现的论文另列“新兴方向”，给出发表日期、实际观察天数和近期引用；
不能与完整观察两年的成熟集合直接排增速名次，也不要因此删除新兴候选。

## 获取引用数据

用可访问学术数据库的当前 API。OpenAlex 可按被引论文 ID 查找施引论文，
并按**施引论文发表日期**过滤。替换占位符后，对每篇论文分别查询 R 和 P：

```text
https://api.openalex.org/works?filter=cites:WORK_ID,from_publication_date:START,to_publication_date:END&per_page=1
```

使用响应的总匹配数，而非第一页条数。记录不含密钥的查询、总数、访问日期及
论文来源链接。这是当前索引中“发表于窗口内的论文所产生的引用”，不是该窗口
数据库新收录的引用事件。索引延迟、预印本日期和历史补录会影响结果。
按当前官方文档核实鉴权；使用已有授权工具，不展示密钥、不擅自开通付费服务。
换数据源时保持两个窗口来源、去重和日期口径一致，不拼接不可比数字。
失败或缺失记未测量，不填零、不猜时间分布。

累计 cited_by_count、自然年 counts_by_year、arXiv 发文量、标题词频与搜索
结果数量都不能冒充滚动一年引用增长。可另列辅助指标，标明含义。
现有 arxiv-trend.mjs 只测发文趋势。历史词池用于发现候选；本次推荐须刷新
引用证据，不能刷新就标历史日期及“未核实当前增长”，不列为已验证热词。

## 计算、稳健性与排序

每篇记录 r_i、p_i；固定集合上计算 C_R=Σr_i、C_P=Σp_i、Δ=C_R−C_P。
C_P>0 时 g=(C_R−C_P)/C_P；C_P=0 时 g=null，标零基数/新兴，
不输出无穷大或用加一伪造倍数。同时报告 n、每篇平均引用、上升论文数/n、
近期引用最多一篇的占比。Σ 是引用边数：同一施引论文引用两篇入选论文贡献
两条，不能标作独立施引论文数。

移除近期引用最多一篇后检查增长方向，判断是否单篇驱动。低基数、小样本、
观察不足、歧义和索引缺失降低可信度，不能仅凭 1→3 的 200% 增长压过较大
且稳定的增长。没有普适热词阈值，也不要包装成统计显著性。

排序顺序：语义准确且属于论文核心内容是硬门槛；同领域可比候选优先多篇
共同增长且增量与增速都有依据者；同等匹配和可信度下优先增速更快者，并展示
体量取舍。零基数/观察不足的新兴词、仅有发文趋势的词分别列示。
代表样本只能表述为“样本文献引用增长较快”；完成明确定义的全量检索才能
表述该检索集合整体趋势。排名是本次候选之间的比较，不是全球排行榜。

## 标题与报告

推荐表包括术语/同义词、论文证据位置、标题适配理由、集合 ID/来源、n、
R/P 日期与计数、Δ、g、单篇集中度、数据限制、推荐级别（优先/可选/仅背景/
未测量/不推荐）、建议位置或自然句式。拒绝的候选也给理由。

完整标题优化给 2–3 个候选：准确简洁版；融入一个最合适的合格增长术语版；
必要时另一个同样准确的任务/社区表达版。热词版准确简洁且证据充分时可列
首选，否则推荐简洁版。无合适词就说明并继续正常标题优化，不编榜、不塞词。
只请求热词推荐时交付术语表及标题用法，不自动改全文或重写摘要。
