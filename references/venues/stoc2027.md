# STOC 2027：投稿与出版要求

官方依据：[STOC 2027 CFP](https://acm-stoc.org/stoc2027/stoc2027-cfp.html)。核查日期：2026-10-29。仅适用于该届会议；实际改稿时重新访问 CFP 和所选阶段的作者指南，记录核查日期及变更，不把本届实验性政策沿用到其他年份。

## 1. 先确定版本与阶段

沿用会话中已明确的阶段；未说明阶段而明确要求“投稿/提交”时，按初投稿处理，“录用后/出版稿”按 camera-ready 处理。

| 项目 | 初投稿（review submission） | 录用后出版稿（proceedings / camera-ready） |
| --- | --- | --- |
| 总篇幅 | 无总页数上限，鼓励完整版本 | CFP 给出的出版稿上限为 12 页；如需区分参考文献/附录是否计入，查最终作者通知，不自行假定豁免 |
| 页面与字号 | Letter，8.5 × 11 英寸；四边 1 英寸；至少 11pt；单栏、单倍行距，留足间距 | 官方 ACM 格式，acmart v2.16 或更新，`\documentclass[sigconf,screen]{acmart}` |
| 首页 | 独立标题页：题目、全部作者姓名及单位、概括贡献的数段摘要 | 按 ACM 官方作者包设置标题、作者、摘要及出版元数据 |
| 作者 | 非匿名；所有列名作者必须是人类 | 按最终作者包提供真实身份和出版信息 |
| 引文样式 | 推荐作者姓氏缩写加年份的字母数字标签，`alpha` 或 `alphaurl` | 按最终 ACM 作者包的 class/bst 要求执行 |

CFP 的单栏、11pt、1 英寸要求不是 `sigconf` 双栏格式。不要把官方出版模板误称为初投模板，也不要把“前 12 页重点阅读”误写成总页数上限。用户明确选择另一阶段的版式时，保留其选择并说明与目标阶段的差异，避免静默切换。

初投可用通用 `article` 的 11pt/Letter 配置配合 `geometry` 实现规定尺寸；这是一种实现方式，不是主办方专用模板。迁移时保留可恢复版本，实际检查纸张、字号、栏数和页边距；出版稿则使用未经修改的官方 class/bst。

## 2. 前 10–12 页应完成的解释

- 标题页之后的前 12 页应向广泛的理论计算机科学研究者介绍问题价值、相对已有工作的贡献、关键技术与概念思想；不能只对本子领域专家可读。
- 在前 10–12 页内讲清主要思想、创新与意义。让读者能复述核心结论、适用条件及证明路线，而非让其从靠后的推导中重建贡献。表达不清可导致 desk rejection。
- 完整证明必须足以核验主要数学主张；长证明可放后文或附录，前部仍应有必要定义、关键条件和证明思路。摘要、目录及前 12 页之外的材料由评审自行决定是否阅读。
- 可在标题页紧后一页放目录；这是可选项，目录不计入上述 12 页。不要为了目录凭空制造其他不计页区域。
- 3–4 个 RQ 可以组织构造、理论与实验，但不是会议规定的结构。按实际贡献选问题，避免把同一结论在 RQ、贡献列表和总结中重复展开。

## 3. 引用、交叉引用与参考文献

以下区分 CFP 的建议与格式硬要求：

- **鼓励**给文献、定理、章节等建立可点击交叉引用；可用 `hyperref` 配合 `cleveref` 或 `varioref`。已有 class 加载 `hyperref` 时不要重复加载或产生 option clash。检查最终 PDF 中实际链接及目标，不能仅检查导言区有包名。
- **要求避免**以“某作者 et al.”缩略叙述引文中的作者；适合时列出全部作者姓氏。作者很多时，可用 `\cite{key} show ...` 或改成带引文的陈述，避免暗示仅第一作者拥有该工作。不要从 `.bib` 中删除共同作者来缩短标签，也不机械禁止被引标题中本身出现的词。
- **推荐**字母数字标签加年份，可用 `\bibliographystyle{alpha}` 或 `alphaurl`；不要将此偏好描述为所有阶段的强制规定。`alphaurl` 便于保留来源链接；必要时确认对应 bst 可用。该偏好不等同于普通 author–year 叙述引用。
- 初投切换 bst 时保留真实条目、引用键和主张归属，核对现有 natbib/BibTeX 兼容性；不要仅为格式便利改用另一套文献后端。录用后遵循最终 ACM 作者包，不用初投的推荐 bst 强行替换其指定样式。
- **鼓励**把参考文献置于稿件末部。另有 AI 实质使用声明时，将参考文献留在正文/附录之后、AI 声明之前，让披露仍处于全文末尾。这是协调两条要求的排版做法，而非 CFP 指定的唯一顺序。

## 4. 生成式 AI 与 LLM 披露

允许使用。实质生成或影响内容的使用，应在提交时以全文末尾的 **AI methodology** 声明披露，注明工具和受影响部分；若 materially 参与研究方法、分析、实验或实现，还需在正文相关位置解释其作用。仅对作者原文做轻微语法、清晰度或文字编辑，不要求披露。AI 使用本身不作为论文评价因素；作者仍承担内容、原创性及参考文献的全部责任。

作者可使用以下官方模板（方括号是待据实填写的字段）：

```text
AI methodology: We used [Tool Name] to assist with [Brief Description of Use]. The tool materially affected [Sections X and Y]. More details can be found in [Section Z]. The authors verified the correctness and originality of all content, including references.
```

按实际使用范围填写，可省略不适用的详细说明交叉引用；不要虚构工具、用途或作者核验。最后一句必须有作者实际核验或明确确认的依据，助手做过检查不自动等同于作者完成核验。已获得的确认继续有效，无需重复询问。AI 不列为作者。

## 5. 影响投稿材料准备的其他政策

| 事项 | STOC 2027 规定 |
| --- | --- |
| 提交文件 | HotCRP，PDF 不限制复制或打印；每位作者至多列名 5 篇投稿 |
| 解说视频 | 必交，20–30 分钟，至少一名列名作者讲解背景、工作及相对已有工作的创新；视频不能引入新主张、修补错误或替代缺失证明。评审可选择不观看，不能据此省略视频 |
| 公开与评审 | 所有投稿将由举办方公开；提交时需同意公开及评审使用 LLM 辅助。视频仅供 PC/评审观看，不公开；评审报告和讨论仍保密 |
| 冲突与重复投稿 | 按 CFP 列出的 COI 类别填报；遵循禁止实质相同工作平行投稿及既有发表政策，保留 CFP 对 Science/Nature 的例外，遇具体情形回查原文 |
| 仓储与出版身份 | 鼓励 arXiv/ECCC/IACR 等仓储发布，但非必需；录用出版前按 ACM 流程准备 ORCID |

已核实日期：论文提交 **2026-11-02 23:59 AoE**；视频提交 **2026-11-16 23:59 AoE**；通知不晚于 **2027-02-01**；camera-ready **2027-04-01**。会议 **2027-06-06 至 10**，AI Day **06-11**。这些是日期快照，不能作为下一届或后续更新的默认值。

这里只指导准备和核查材料；不会授权自动提交、上传、公开发布或联系举办方。视频的进一步细节应从 CFP 的官方 author video instructions 链接读取。

## 6. 改稿后的核查范围

交付时写明阶段、所用官方来源和核查日期、实际 PDF 页数及计页口径。检查标题页/可选目录、前 12 页的可理解性与主要证明路线、作者信息、链接和引文样式、AI 声明位置及真实性；编译后排除新增未解析引用和溢出，查看受影响页面。只做局部格式调整不触发无关实验、整篇重写或全量参考文献重审。
